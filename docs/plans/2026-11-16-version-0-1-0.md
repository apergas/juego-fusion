# Version 0.1.0 (the playable jar) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use boost:subagent-driven-development (recommended) or boost:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the first playable version of *Fusión de criaturas*: a portrait jar where creatures dropped with one finger roll, merge two by two into the next of an 8-link chain, score points and combos, and lose when the jar overflows; with a title, a bestiary, options, pause, a saved record, a self-playing autoplay and the installable web build.

**Architecture:** Three kinds of script (pure rules, static builders, nodes) as in Villaclaro. `TitleScreen` owns the `AudioDirector`, the `GameOptions` and the `Profile` (record + bestiary) and creates a `Game` per session. `Game` is a coordinator over its pieces (`Hud`, `PauseWindow`, `EndWindow`, `GameAutoplay`): it owns the round's `GameState` and the game's clock, builds a new `Jar` each round, and plays back what the rules (`Chain`, `Spawner`, `Scoring`, `Danger`, `Bestiary`, `JarSpec`) decide. The `Jar` (3D, orthographic, Jolt physics locked to a plane) only reports (`released`, `merge_found`) through its pieces `DropAim`, `MergeWatcher`, `DangerLine` and `FusionFx`.

**Tech Stack:** Godot 4.7.2, GDScript, Compatibility renderer, Jolt Physics, the design system core (git submodule `addons/design_system/`), Git Bash on Windows (`./tools/godot.cmd`).

## Decisions this plan takes where the spec leaves room

- **Where the jar's numbers live:** a pure rule `JarSpec` (measures, camera fit, physics numbers, "settled" time). `Danger`, `DropAim`, the autoplay and the builders all read it.
- **Camera:** orthographic, `KEEP_HEIGHT`, centred at x 0, y `VIEW_CENTER_Y` 5.1; its size is `max(13.5, 7.6 / aspect)` so the jar (6.0 + frame) and 3.2 m of HUD room above it always fit (aspect expand).
- **Physics starting values:** friction 0.4, bounce 0.1 (spec), angular damp 1.0, linear damp 0 (Godot default), mass = (radius / 0.30)², continuous CD on. A merged creature's collider grows from 0.6 to its full radius in 0.2 s, so it pushes neighbours aside instead of kicking them. Task 5 checks the feel on recorded frames and gives the order in which to change them.
- **Interface scale:** `DisplaySettings.UI_SCALE` = 1.25 (`content_scale_factor`) on every device: the canvas is 720 wide and a phone shows it ~360 points wide, so the core's 24 px body becomes ~15 points. All UI sizes and HUD offsets below are in those scaled units.
- **Buttons:** every big button is the core's `ACTION_BUTTON` pill at least `button-big-w` × `button-big-h` (400 × 80, over `touch-target`); option selectors and the pause button are at least `touch-target`.
- **Windows:** one node base, `ModalWindow` (scrim + core window + title + big buttons), for the end, the pause, the bestiary and the options.
- **The notice** («¡Nueva criatura: …!») follows the core's Notice: 0.2 s fade, 4 s, one at a time, under the HUD's top row.
- **Saving:** the options live inside `save.json` (the spec's one file), with the record and the discovered ids. Saved after each round, at each discovery and at each options change.
- **Autoplay extras not named in the spec,** needed by this plan's own checks: `--autoplay-save` (prints the save written and read back; the skill's round trip) and `--autoplay-menu` (tours the title, the bestiary, the options and the pause, for frames). The merge of two dragons prints `Fusión: dragon + dragon (combo n)`. The averages line also says how many rounds reached creature 6.
- **From the screens mockup** (`docs/design-system/maqueta.html`, approved direction; this plan's palette values govern over the mockup's): (1) a creature's ears, wings and horns never reach past its collision radius sideways (they fold up or back), so nothing pokes through the jar's wall; Task 10 checks it on a frame of the dragon and the bat against a wall. (2) The pause window also has an **Opciones** button that opens the same `OptionsWindow` as the title, over the pause; Task 11 adds it between Seguir and Empezar de nuevo. (3) «Siguiente» shows its creature at the HUD's own size (`NEXT_VIEW`), never its jar size.
- **Frames at a phone's size:** `--write-movie` ignores `--resolution`, so phone-shaped frames use a temporary, git-ignored `override.cfg` with a 720 × 1480 viewport: the same canvas a 360 × 740 phone gets with aspect expand.

Create `scripts/audio/sfx_library.gd`:

```gdscript
class_name SfxLibrary extends RefCounted
## Sound effects in the style of sfxr, synthesized in code. Copied from Villaclaro's
## scripts/audio/sfx_library.gd, trimmed to this game's effects, with the 16-bit stream writer of
## Villaclaro's MusicLibrary (there is no music yet). Each effect is a Dictionary of parameters:
## wave ("square", "triangle" or "noise"), "from" and "to" (pitch in Hz at the start and at the
## end, slid linearly; for noise, how many new random values per second), "time" (seconds),
## "volume", "decay" (power of the fade-out: 1 is linear, higher fades sooner) and optional
## "notes" (pitches played one after the other, each "time" long, instead of the slide). The
## «¡plop!» of a merge has one effect per level made (plop_id()): the bigger the creature, the
## lower it sounds. build() caches each stream.

const CURSOR := "cursor"
const ACCEPT := "accept"
const CANCEL := "cancel"
const DROP := "drop"
const PRIZE := "prize"
const LOSE := "lose"
const NEW := "new"
const RATE := 22050
const NOISE_SEED := 4321
## Samples of fade-in at the start of every sound (no click).
const FADE_IN := 40
## The plop of level 2 starts here; each level up is PLOP_STEP times lower.
const PLOP_BASE_HZ := 760.0
const PLOP_STEP := 0.84
const PLOP_PREFIX := "plop_"
const SOUNDS := {
	CURSOR: {"wave": "square", "from": 880.0, "to": 880.0, "time": 0.04, "volume": 0.25,
		"decay": 1.0},
	ACCEPT: {"wave": "square", "notes": [660.0, 990.0], "time": 0.06, "volume": 0.3,
		"decay": 1.0},
	CANCEL: {"wave": "square", "from": 440.0, "to": 220.0, "time": 0.09, "volume": 0.3,
		"decay": 1.0},
	# A soft tick: the creature lets go.
	DROP: {"wave": "triangle", "from": 520.0, "to": 380.0, "time": 0.05, "volume": 0.25,
		"decay": 1.0},
	# Two dragons vanish: a bright arpeggio.
	PRIZE: {"wave": "triangle", "notes": [783.99, 987.77, 1174.66, 1567.98, 1975.53],
		"time": 0.06, "volume": 0.5, "decay": 0.5},
	# The jar overflows: a long fall, low.
	LOSE: {"wave": "square", "from": 330.0, "to": 70.0, "time": 0.9, "volume": 0.35,
		"decay": 0.8},
	# A creature seen for the first time.
	NEW: {"wave": "triangle", "notes": [880.0, 1174.66], "time": 0.07, "volume": 0.35,
		"decay": 0.5},
}

static var _cache := {}


## The plop of a merge that makes a creature of level.
static func plop_id(level: int) -> String:
	return "%s%d" % [PLOP_PREFIX, level]


## Drops the cached streams, so none is left at exit (AudioDirector._exit_tree()).
static func clear_cache() -> void:
	_cache.clear()


static func build(id: String) -> AudioStreamWAV:
	if _cache.has(id):
		return _cache[id]
	var sound := _sound(id)
	var samples := PackedFloat32Array()
	if sound.has("notes"):
		for pitch: float in sound.notes:
			samples.append_array(_render(sound, pitch, pitch))
	else:
		samples = _render(sound, sound.from, sound.to)
	var stream := to_stream(samples)
	_cache[id] = stream
	return stream


## 16-bit mono stream at RATE from samples in -1..1 (clipped).
static func to_stream(samples: PackedFloat32Array) -> AudioStreamWAV:
	var data := PackedByteArray()
	data.resize(samples.size() * 2)
	for i in samples.size():
		data.encode_s16(i * 2, int(clampf(samples[i], -1.0, 1.0) * 32767.0))
	var stream := AudioStreamWAV.new()
	stream.format = AudioStreamWAV.FORMAT_16_BITS
	stream.mix_rate = RATE
	stream.stereo = false
	stream.data = data
	return stream


## The parameters of id: a plop is made for its level, the rest are in SOUNDS.
static func _sound(id: String) -> Dictionary:
	if id.begins_with(PLOP_PREFIX):
		var level := id.trim_prefix(PLOP_PREFIX).to_int()
		var base := PLOP_BASE_HZ * pow(PLOP_STEP, level - 2)
		return {"wave": "triangle", "from": base * 0.7, "to": base * 1.5,
			"time": 0.08 + 0.012 * level, "volume": 0.5, "decay": 1.6}
	return SOUNDS[id]


## One slide from pitch_from to pitch_to, sound.time long, fading out.
static func _render(sound: Dictionary, pitch_from: float, pitch_to: float) -> PackedFloat32Array:
	var count := int(float(sound.time) * RATE)
	var volume: float = sound.volume
	var decay: float = sound.decay
	var wave: String = sound.wave
	var rng := RandomNumberGenerator.new()
	rng.seed = NOISE_SEED
	var samples := PackedFloat32Array()
	samples.resize(count)
	var phase := 0.0
	var held := 0.0
	for i in count:
		var t := float(i) / count
		var pitch := lerpf(pitch_from, pitch_to, t)
		phase += pitch / RATE
		var wrapped := phase >= 1.0
		if wrapped:
			phase -= floorf(phase)
		var value: float
		match wave:
			"noise":
				if wrapped:
					held = rng.randf_range(-1.0, 1.0)
				value = held
			"triangle":
				value = 4.0 * absf(phase - 0.5) - 1.0
			_:
				value = 1.0 if phase < 0.5 else -1.0
		var env := pow(1.0 - t, decay)
		if i < FADE_IN:
			env *= float(i) / FADE_IN
		samples[i] = value * volume * env
	return samples
```

```gdscript
	for i in SFX_PLAYERS:
		var player := AudioStreamPlayer.new()
		add_child(player)
		_sfx.append(player)


## Empties the stream cache, so no stream is left at exit.
func _exit_tree() -> void:
	SfxLibrary.clear_cache()


func play_sfx(id: String) -> void:
	var player := _sfx[_next_sfx]
	_next_sfx = (_next_sfx + 1) % SFX_PLAYERS
	player.stream = SfxLibrary.build(id)
	player.volume_linear = 0.0 if _muted else sfx_volume
	if not _no_playback:
		player.play()


## Volume 0..1 of the next effects.
func set_volume(sfx: float) -> void:
```

```gdscript
## The jar's measures and the physics numbers of its creatures, in metres of the world. Pure: no
## nodes. The floor is at y 0 and the walls at x ±WIDTH/2. The camera looks at x 0, y
## VIEW_CENTER_Y and always shows at least VIEW_WIDTH × VIEW_HEIGHT (camera_size()): the jar

const WIDTH := 6.0
const HEIGHT := 8.4
## The danger line, measured from the floor.
const LINE_Y := 7.4

const WAIT_Y := 8.0

const SETTLE_TIME := 1.0

## waiting creature plus 1.35 m under the floor.
const VIEW_WIDTH := 7.6
const VIEW_HEIGHT := 13.5
const VIEW_CENTER_Y := 5.1
## Physics: friction and bounce of the creatures and the jar (the spec's starting values),
## the creatures' angular damping (they roll a little and settle soon).
const FRICTION := 0.4
const BOUNCE := 0.1
const ANGULAR_DAMP := 1.0
## A creature of this radius (the Gota de rocío) weighs 1; the mass grows with the square of the
## radius (the area in the plane).
const MASS_RADIUS := 0.3
## A merged creature's collider grows from GROW_FROM times its radius to the whole of it in
## GROW_TIME seconds: it pushes its neighbours aside instead of kicking them.
const GROW_FROM := 0.6
const GROW_TIME := 0.2


## x kept inside the jar for a creature of radius.
static func clamp_x(x: float, radius: float) -> float:
	return clampf(x, -WIDTH / 2.0 + radius, WIDTH / 2.0 - radius)


## The orthographic camera's height (KEEP_HEIGHT) for a screen of aspect (width / height).
static func camera_size(aspect: float) -> float:
	return maxf(VIEW_HEIGHT, VIEW_WIDTH / aspect)

	return pow(radius / MASS_RADIUS, 2.0)
```

```gdscript
class_name JarBuilder extends RefCounted
## Constructor: static; builds the scene of the jar for its caller and keeps no state but the
## shared physics material: the light, the backdrop (the purple gradient and its slow motes of
## light), the jar (its invisible walls and floor, its glass frame and back), the orthographic
## camera, thin lines (the danger line, the aim line) and their materials. The colours are tokens
## of the game's layer (scene-*, jar-*...), read with UiTokens.color().

## The jar's glass back, behind every creature (the biggest is 1.48 m round).
const BACK_Z := -1.8
## Lines and effects drawn in front of every creature.
const FRONT_Z := 1.7
const BACKDROP_Z := -6.0
const BACKDROP_SIZE := Vector2(40.0, 26.0)
## The glass frame seen around the jar, and its depth.
const FRAME := 0.18
const FRAME_DEPTH := 0.5
## The invisible walls and floor: thick, and tall enough that nothing jumps out.
const COLLIDER := 1.0
const COLLIDER_HEIGHT := 16.0
const COLLIDER_DEPTH := 2.0

const MOTE_LIFETIME := 12.0

shader_type spatial;
render_mode unshaded, cull_disabled;
uniform vec4 top_color : source_color;
uniform vec4 bottom_color : source_color;
void fragment() {
	ALBEDO = mix(top_color.rgb, bottom_color.rgb, UV.y);
}
"""

static var _physics: PhysicsMaterial


## The light, the gradient behind everything and (with motes) the floating motes of light.
static func backdrop(root: Node3D, motes := true) -> void:
	light(root)
	var quad := QuadMesh.new()
	quad.size = BACKDROP_SIZE
	var shader := Shader.new()
	shader.code = GRADIENT_SHADER
	var material := ShaderMaterial.new()
	material.shader = shader
	material.set_shader_parameter("top_color", UiTokens.color(&"scene-top"))
	material.set_shader_parameter("bottom_color", UiTokens.color(&"scene-bottom"))
	var back := MeshInstance3D.new()
	back.mesh = quad
	back.material_override = material
	back.position = Vector3(0.0, JarSpec.VIEW_CENTER_Y, BACKDROP_Z)
	root.add_child(back)
	if motes:
		root.add_child(_motes())


## The sun and the ambient light the creatures are seen with; clear leaves the background
## transparent (a CreatureView's own world).
static func light(root: Node, clear := false) -> void:
	var environment := Environment.new()
	environment.background_mode = Environment.BG_CLEAR_COLOR if clear else Environment.BG_COLOR
	environment.background_color = UiTokens.color(&"scene-bottom")
	environment.ambient_light_source = Environment.AMBIENT_SOURCE_COLOR
	environment.ambient_light_color = Color.WHITE
	environment.ambient_light_energy = AMBIENT_ENERGY
	var world := WorldEnvironment.new()
	world.environment = environment
	root.add_child(world)
	var sun := DirectionalLight3D.new()
	sun.rotation_degrees = LIGHT_ROTATION
	sun.light_energy = LIGHT_ENERGY
	root.add_child(sun)


## The jar: invisible static walls and floor with the creatures' physics material, the dark
## glass back and the light frame.
static func jar(root: Node3D) -> void:
	var half := JarSpec.WIDTH / 2.0
	root.add_child(_wall(Vector3(JarSpec.WIDTH + 2.0 * COLLIDER, COLLIDER, COLLIDER_DEPTH),
		Vector3(0.0, -COLLIDER / 2.0, 0.0)))
	for side: float in [-1.0, 1.0]:
		root.add_child(_wall(Vector3(COLLIDER, COLLIDER_HEIGHT, COLLIDER_DEPTH),
			Vector3(side * (half + COLLIDER / 2.0), COLLIDER_HEIGHT / 2.0, 0.0)))
	root.add_child(_box(Vector3(JarSpec.WIDTH, JarSpec.HEIGHT, 0.02),
		Vector3(0.0, JarSpec.HEIGHT / 2.0, BACK_Z), unshaded(UiTokens.color(&"jar-back"))))
	var frame := StandardMaterial3D.new()
	frame.albedo_color = UiTokens.color(&"jar-frame")
	frame.transparency = BaseMaterial3D.TRANSPARENCY_ALPHA
	frame.roughness = 0.3
	root.add_child(_box(Vector3(JarSpec.WIDTH + 2.0 * FRAME, FRAME, FRAME_DEPTH),
		Vector3(0.0, -FRAME / 2.0, 0.0), frame))
	for side: float in [-1.0, 1.0]:
		root.add_child(_box(Vector3(FRAME, JarSpec.HEIGHT + FRAME, FRAME_DEPTH),
			Vector3(side * (half + FRAME / 2.0), (JarSpec.HEIGHT - FRAME) / 2.0, 0.0), frame))


## The orthographic camera, head on, made current. The owner calls fit_camera() now and on
## every change of the window's size.
static func camera(root: Node3D) -> Camera3D:
	var result := Camera3D.new()
	result.projection = Camera3D.PROJECTION_ORTHOGONAL
	result.keep_aspect = Camera3D.KEEP_HEIGHT
	result.size = JarSpec.VIEW_HEIGHT
	result.near = 0.1
	result.far = 50.0
	result.position = Vector3(0.0, JarSpec.VIEW_CENTER_Y, CAMERA_Z)
	root.add_child(result)
	result.current = true
	return result


static func fit_camera(view_camera: Camera3D) -> void:
	var view := view_camera.get_viewport().get_visible_rect().size
	view_camera.size = JarSpec.camera_size(view.x / view.y)


## A thin flat bar facing the camera (the danger line, the aim line), unlit, in color.
static func line(width: float, height: float, color: Color) -> MeshInstance3D:
	return _box(Vector3(width, height, 0.02), Vector3.ZERO, unshaded(color))


static func unshaded(color: Color) -> StandardMaterial3D:
	var material := StandardMaterial3D.new()
	material.shading_mode = BaseMaterial3D.SHADING_MODE_UNSHADED
	material.albedo_color = color
	material.transparency = BaseMaterial3D.TRANSPARENCY_ALPHA
	material.cull_mode = BaseMaterial3D.CULL_DISABLED
	return material


## Friction and bounce of JarSpec, shared by the creatures and the jar.
static func physics_material() -> PhysicsMaterial:
	if _physics == null:
		_physics = PhysicsMaterial.new()
		_physics.friction = JarSpec.FRICTION
		_physics.bounce = JarSpec.BOUNCE
	return _physics


static func _box(size: Vector3, at: Vector3, material: Material) -> MeshInstance3D:
	var mesh := BoxMesh.new()
	mesh.size = size
	var node := MeshInstance3D.new()
	node.mesh = mesh
	node.material_override = material
	node.position = at
	return node


static func _wall(size: Vector3, at: Vector3) -> StaticBody3D:
	var body := StaticBody3D.new()
	body.physics_material_override = physics_material()
	body.position = at
	var box := BoxShape3D.new()
	box.size = size
	var shape := CollisionShape3D.new()
	shape.shape = box
	body.add_child(shape)
	return body


## Motes of light that rise slowly behind the jar, fading in and out.
static func _motes() -> CPUParticles3D:
	var particles := CPUParticles3D.new()
	particles.amount = MOTES
	particles.lifetime = MOTE_LIFETIME
	particles.preprocess = MOTE_LIFETIME
	particles.emission_shape = CPUParticles3D.EMISSION_SHAPE_BOX
	particles.emission_box_extents = MOTE_AREA
	particles.direction = Vector3.UP
	particles.spread = 25.0
	particles.gravity = Vector3.ZERO
	particles.initial_velocity_min = 0.08
	particles.initial_velocity_max = 0.22
	particles.scale_amount_min = 0.04
	particles.scale_amount_max = 0.1
	var fade := Gradient.new()
	fade.offsets = PackedFloat32Array([0.0, 0.2, 0.8, 1.0])
	fade.colors = PackedColorArray([Color.TRANSPARENT, Color.WHITE, Color.WHITE,
		Color.TRANSPARENT])
	particles.color_ramp = fade
	var quad := QuadMesh.new()
	quad.size = Vector2.ONE
	var material := unshaded(UiTokens.color(&"scene-mote"))
	material.vertex_color_use_as_albedo = true
	quad.material = material
	particles.mesh = quad
	particles.position = Vector3(0.0, JarSpec.VIEW_CENTER_Y, BACKDROP_Z + 1.0)
	return particles
```

```gdscript

## Turns the profile and the options into the Dictionary SaveStore writes as JSON, and back.
## Pure: no nodes, no files. VERSION 1: {"version", "best_score", "discovered", "options"}. A save
## of another version, or one a played game can't reach (a negative or broken record, an unknown
## or repeated id, no options), is not valid, and nothing of it is applied: the game starts from
## scratch. JSON reads every number as a float, so apply() converts them.

const VERSION := 1


static func from(profile: Profile, options: GameOptions) -> Dictionary:
	return {"version": VERSION, "best_score": profile.best_score,
		"discovered": profile.discovered.duplicate(), "options": options.to_dict()}


static func is_valid(data: Dictionary) -> bool:
	if not _whole(data.get("version")) or int(data.version) != VERSION:
		return false
	var best: Variant = data.get("best_score")
	if not _whole(best) or int(best) < 0:
		return false
	var ids: Variant = data.get("discovered")
	if not ids is Array:
		return false
	var seen := {}
	for id: Variant in ids:

		return false

	profile.discovered.assign(data.discovered)

static func _whole(value: Variant) -> bool:
	if value is int:
		return true
	return value is float and is_equal_approx(value, roundf(value))
```

Create `scripts/jar/low_poly.gd` (copied from Villaclaro's `scripts/battle/low_poly.gd`, trimmed to what the creatures use: no bush, no MultiMesh, no hemisphere, disc or merge):

```gdscript
class_name LowPoly extends RefCounted
## Constructor: static; builds faceted low-poly meshes for its caller and keeps no state. A blob
## is a lathe of rings taken from a side profile, every other ring turned half a segment, with
## one normal per face (flat shading), so it reads as a cut gem instead of a smooth sphere: the
## creatures' balls, the seta's cap and the golem's moss are blobs. The primitives (sphere, cone,
## cylinder) are their eyes, ears, horns and wings. Copied from Villaclaro's
## scripts/battle/low_poly.gd, trimmed to what the creatures use.


## Lathe of profile (x = radius, y = height, bottom to top) around +Y with segments sides and
## flat normals.
static func blob(profile: Array[Vector2], segments: int) -> ArrayMesh:
	var rings: Array[PackedVector3Array] = []
	for i in profile.size():
		var ring := PackedVector3Array()
		var offset := 0.5 * (i % 2)
		for s in segments:
			var angle := TAU * (s + offset) / segments
			ring.append(Vector3(sin(angle) * profile[i].x, profile[i].y,
				cos(angle) * profile[i].x))
		rings.append(ring)
	var st := SurfaceTool.new()
	st.begin(Mesh.PRIMITIVE_TRIANGLES)
	# Smooth group 0xFFFFFFFF: no vertex is shared, every face keeps its own normal.
	st.set_smooth_group(0xFFFFFFFF)
	for i in rings.size() - 1:
		var lo := rings[i]
		var hi := rings[i + 1]
		for s in segments:
			var n := (s + 1) % segments
			_triangle(st, lo[s], hi[s], lo[n])
			_triangle(st, lo[n], hi[s], hi[n])
	st.generate_normals()
	return st.commit()


## A sphere of radius with 10 sides and 5 rings.
static func sphere(radius: float) -> SphereMesh:
	var mesh := SphereMesh.new()
	mesh.radius = radius
	mesh.height = radius * 2.0
	mesh.radial_segments = 10
	mesh.rings = 5
	return mesh


## A cylinder of radius and height with 8 sides, centred on its middle.
static func cylinder(radius: float, height: float) -> CylinderMesh:
	var mesh := CylinderMesh.new()
	mesh.top_radius = radius
	mesh.bottom_radius = radius
	mesh.height = height
	mesh.radial_segments = 8
	return mesh


## A cone pointing up +Y: a cylinder whose top radius is 0.
static func cone(radius: float, height: float) -> CylinderMesh:
	var mesh := cylinder(radius, height)
	mesh.top_radius = 0.0
	return mesh


## Skips triangles that collapse at the profile's tips (radius 0).
static func _triangle(st: SurfaceTool, a: Vector3, b: Vector3, c: Vector3) -> void:
	if a.is_equal_approx(b) or b.is_equal_approx(c) or a.is_equal_approx(c):
		return
	st.add_vertex(a)
	st.add_vertex(b)
	st.add_vertex(c)
```

```gdscript
class_name CreatureLooks extends RefCounted
## Constructor: static; builds the figure of a creature from its CreatureData for its caller
## (CreatureBody, DropAim) and keeps no state but a cache of materials. Every creature is a
## faceted ball (LowPoly.blob) facing the camera (+Z) with its eyes. silhouette paints every part
## in creature-silhouette, unlit.

const RINGS := 6
const EYE_COLOR := Color("#1a1020")
const SHINE_COLOR := Color.WHITE
const ROUGHNESS := 0.85

	var r := data.radius
	_add(root, LowPoly.blob(_ball(r), SEGMENTS), _paint(data.color, silhouette))
	_eyes(root, r, 0.12, silhouette)

## A ball's side profile, bottom to top, RINGS + 1 rings.
static func _ball(radius: float) -> Array[Vector2]:
	var profile: Array[Vector2] = []
	for i in RINGS + 1:
		var angle := PI * i / RINGS
		profile.append(Vector2(radius * sin(angle), -radius * cos(angle)))
	return profile


## Two eyes on the front of a ball of radius r, at height y (times r), each with its shine.
static func _eyes(root: Node3D, r: float, y: float, silhouette: bool) -> void:
	for side: float in [-1.0, 1.0]:
		_add(root, LowPoly.sphere(0.14 * r), _paint(EYE_COLOR, silhouette),
			Vector3(side * 0.33 * r, y * r, 0.86 * r), Vector3.ZERO, Vector3(1.0, 1.15, 0.6))
		_add(root, LowPoly.sphere(0.05 * r), _paint(SHINE_COLOR, silhouette),
			Vector3(side * 0.33 * r + 0.04 * r, y * r + 0.06 * r, 0.95 * r))


static func _add(root: Node3D, mesh: Mesh, material: Material, at := Vector3.ZERO,
		degrees := Vector3.ZERO, scale := Vector3.ONE) -> MeshInstance3D:
	var node := MeshInstance3D.new()
	node.mesh = mesh
	node.material_override = material
	node.position = at
	node.rotation_degrees = degrees
	node.scale = scale
	root.add_child(node)
	return node


## The lit material of color (cached), or the silhouette's.
static func _paint(color: Color, silhouette: bool) -> Material:
	if silhouette:
		return _material(UiTokens.color(&"creature-silhouette"), true)
	return _material(color, false)


static func _material(color: Color, flat: bool) -> Material:
	var key := "%s:%s" % [color.to_html(), flat]
	if not _materials.has(key):
		var material := StandardMaterial3D.new()
		material.albedo_color = color
		material.roughness = ROUGHNESS
		if flat:
			material.shading_mode = BaseMaterial3D.SHADING_MODE_UNSHADED
		_materials[key] = material
	return _materials[key]
```

```gdscript
class_name GameAutoplay extends Node
## Node, a piece of Game, only with --autoplay: plays rounds by itself. Each time a creature
## waits it thinks THINK seconds and drops it over the highest settled creature of its own level,
## or, with none, where the pile is lowest (_choose_x()). It prints what a reader of the log
## follows. Uses only Game's Callables (drop) and the Jar's public functions; never stores Game
## or a Jar (it asks jar_of each time: the Jar changes every round).

const THINK := 0.5
## How finely it looks for the lowest place of the pile, in metres.
const SCAN_STEP := 0.25

## drop.call(x): Game.drop_at().
var drop: Callable
var _state_of: Callable
var _jar_of: Callable
var _think := THINK


## state_of and jar_of return the current GameState and Jar.
func setup(state_of: Callable, jar_of: Callable) -> void:
	_state_of = state_of
	_jar_of = jar_of


## Every physics frame (Game._physics_process()).
func step(delta: float) -> void:
	var state: GameState = _state_of.call()
	if state.over or not state.can_drop:
		_think = THINK
		return
	_think -= delta
	if _think > 0.0:
		return
	_think = THINK
	var jar: Jar = _jar_of.call()
	drop.call(_choose_x(Chain.data(state.current), jar.creatures()))


func on_dropped(id: String, x: float) -> void:
	print("Suelta: %s en x=%.1f" % [id, x])


## Over the highest settled creature of data's level; with none, where the pile is lowest
## (the middle wins a tie).
func _choose_x(data: CreatureData, bodies: Array[CreatureBody]) -> float:
	var best: CreatureBody = null
	for body in bodies:
		if body.merged or body.data.level != data.level or body.age < JarSpec.SETTLE_TIME:
			continue
		if best == null or body.position.y > best.position.y:
			best = body
	if best:
		return JarSpec.clamp_x(best.position.x, data.radius)
	var low_x := 0.0
	var low_y := INF
	var x := -JarSpec.WIDTH / 2.0 + data.radius
	while x <= JarSpec.WIDTH / 2.0 - data.radius + 0.001:
		var y := _rest_height(x, data.radius, bodies)
		if y < low_y - 0.01 or (absf(y - low_y) <= 0.01 and absf(x) < absf(low_x)):
			low_y = y
			low_x = x
		x += SCAN_STEP
	return low_x


## Where the centre of a creature of radius falling at x would come to rest on the pile.
func _rest_height(x: float, radius: float, bodies: Array[CreatureBody]) -> float:
	var y := radius
	for body in bodies:
		var reach := body.data.radius + radius
		var dx := absf(body.position.x - x)
		if dx < reach:
			y = maxf(y, body.position.y + sqrt(reach * reach - dx * dx))
	return y
```

```gdscript
class_name Scoring extends RefCounted
## Points, combos and the record. Pure: no nodes; Game owns the combo's clock (GameState
## .since_merge) and asks here. A merge less than COMBO_WINDOW seconds after the one before
## raises the combo; any other starts it again at 1. The points of a merge (Chain.merge_points())
## are multiplied by 1 + COMBO_STEP × (combo − 1), up to COMBO_MAX.

const COMBO_WINDOW := 1.0
const COMBO_STEP := 0.25
const COMBO_MAX := 3.0


## The combo after a merge that comes since seconds after the one before.
static func next_combo(combo: int, since: float) -> int:
	return combo + 1 if since < COMBO_WINDOW else 1


static func multiplier(combo: int) -> float:
	return minf(1.0 + COMBO_STEP * (combo - 1), COMBO_MAX)


static func points(base: int, combo: int) -> int:
	return roundi(base * multiplier(combo))


## The end of a round: true (and the profile's record raised) if score beats it.
static func record(profile: Profile, score: int) -> bool:
	if score <= profile.best_score:
		return false
	profile.best_score = score
	return true
```

```gdscript
## Node, a piece of Jar: finds two creatures of the same level touching. Every physics frame
## (step(), called by Jar) it asks each creature for the bodies it touches (its contact monitor)
## and pairs it with the first equal one still free; both are marked merged at once, so a

			break
	# After the loop: a merge changes the list of bodies.
	for pair in pairs:
		touched.emit(pair[0], pair[1])
```

```gdscript
class_name Danger extends RefCounted
## When the jar overflows. Pure: no nodes; Game keeps the count (GameState.danger_time). A settled
## creature (JarSpec.SETTLE_TIME in the jar) whose top is over JarSpec.LINE_Y starts the count;
## LOSE_TIME seconds in a row lose the round, and the count goes back to 0 the moment none is
## over (a merge, or one that rolls down). While it counts the line blinks, from BLINK_SLOW to
## BLINK_FAST times a second as the time runs out.

const LOSE_TIME := 3.0
const BLINK_SLOW := 2.0
const BLINK_FAST := 8.0


## top: the highest top of the settled creatures (-INF for none).
static func is_over(top: float) -> bool:
	return top > JarSpec.LINE_Y


static func step(count: float, over: bool, delta: float) -> float:
	return count + delta if over else 0.0


## How much of LOSE_TIME has gone, 0..1.
static func fraction(count: float) -> float:
	return clampf(count / LOSE_TIME, 0.0, 1.0)


static func lost(count: float) -> bool:
	return count >= LOSE_TIME


## Blinks a second at fraction of the count.
static func blink_hz(at_fraction: float) -> float:
	return lerpf(BLINK_SLOW, BLINK_FAST, at_fraction)
```

```gdscript
class_name Game extends Node
## One play session, created by TitleScreen (setup() before add_child); run on its own
## (res://scenes/game/game.tscn) it loads the save and makes its own AudioDirector. A
## coordinator: it owns the round's GameState, the current Jar (a new one each round), the game's
## clock (the round's time, the wait after a drop, the combo's clock and the danger's count, all
## on the physics frame) and the profile's record, which it saves at the end of each round. The
## Jar only reports (released, merge_found); the rules (Chain, Spawner, Scoring, Danger) decide;
## Game plays it back through the Jar and the windows. Its pieces: the EndWindow (created at the
## end of a round) and GameAutoplay (only with --autoplay). Esc goes back to the title
## (quit_to_title).

signal quit_to_title

var state: GameState
var _audio: AudioDirector
var _options: GameOptions
var _profile: Profile
var _jar: Jar
var _end: EndWindow
var _autopilot: GameAutoplay
## How many rounds this session has started: the seed of each is --seed=<n> plus it.
var _round := 0


## audio, options and profile come from the title screen.
func setup(audio: AudioDirector, options: GameOptions, profile: Profile) -> void:
	_audio = audio
	_options = options
	_profile = profile


func _ready() -> void:
	if _options == null:
		_options = GameOptions.new()
		_profile = Profile.new()
		SaveStore.load_into(_profile, _options)
		DisplaySettings.apply(get_window(), _options)
	if _audio == null:
		_audio = AudioDirector.new()
		add_child(_audio)
		_audio.set_volume(_options.sfx_volume)
	if RunFlags.autoplay():
		_autopilot = GameAutoplay.new()
		_autopilot.setup(func() -> GameState: return state, func() -> Jar: return _jar,
			RunFlags.autoplay_games(), RunFlags.autoplay_save())
		_autopilot.drop = drop_at
		_autopilot.restart = _restart
		_autopilot.quit_requested.connect(_quit)
		add_child(_autopilot)
	_start_round()


func _physics_process(delta: float) -> void:
	if not state.over:
		_tick(delta)
	if _autopilot:
		_autopilot.step(delta)


func _unhandled_input(event: InputEvent) -> void:
	if event.is_action_pressed("ui_cancel"):
		get_viewport().set_input_as_handled()
		_quit()


## Drops the waiting creature at x (kept inside the jar). The Jar's released and the autoplay
## call it; it does nothing while nothing waits.
func drop_at(x: float) -> void:
	if state.over or not state.can_drop:
		return
	var data := Chain.data(state.current)
	var body := _jar.drop(data, x)
	state.can_drop = false
	state.wait_left = Spawner.DROP_WAIT
	_audio.play_sfx(SfxLibrary.DROP)
	if _autopilot:
		_autopilot.on_dropped(data.id, body.position.x)
	_note_creature(data)
	Spawner.advance(state)


## One physics frame of the round: its clocks, the jar, then the danger's count.
func _tick(delta: float) -> void:
	state.elapsed += delta
	state.since_merge += delta
	if not state.can_drop:
		state.wait_left -= delta
		if state.wait_left <= 0.0:
			_present()
	_jar.step(delta)
	var over := Danger.is_over(_jar.highest_top(JarSpec.SETTLE_TIME))
	state.danger_time = Danger.step(state.danger_time, over, delta)
	_jar.show_danger(Danger.fraction(state.danger_time))
	if Danger.lost(state.danger_time):
		_lose()


## A new round: a new GameState, its first creatures and a new Jar in place of the old one.
func _start_round() -> void:
	if _jar:
		remove_child(_jar)
		_jar.queue_free()
	var seed_flag := RunFlags.seed()
	state = GameState.new(seed_flag + _round if seed_flag >= 0 else -1)
	_round += 1
	Spawner.start(state)
	_jar = Jar.new()
	_jar.released.connect(drop_at)
	_jar.merge_found.connect(_on_merge_found)
	add_child(_jar)
	_present()


## The waiting creature appears at the top of the jar.
func _present() -> void:
	state.can_drop = true
	state.wait_left = 0.0
	_jar.show_waiting(Chain.data(state.current))


## Two equal creatures touch (the Jar's merge_found): the combo and the points (Scoring), then the
## creature they make (Chain), or nothing for two of the last level.
func _on_merge_found(a: CreatureBody, b: CreatureBody) -> void:
	if state.over:
		return
	var level := a.data.level
	state.combo = Scoring.next_combo(state.combo, state.since_merge)
	state.since_merge = 0.0
	var points := Scoring.points(Chain.merge_points(level), state.combo)
	state.score += points
	var made := Chain.next_level(level)
	if made == 0:
		_jar.vanish(a, b)
		_audio.play_sfx(SfxLibrary.PRIZE)
	else:
		var data := Chain.data(made)
		_jar.merge(a, b, data)
		_audio.play_sfx(SfxLibrary.plop_id(made))
		_note_creature(data)
	if _autopilot:
		_autopilot.on_merged(Chain.IDS[made - 1] if made > 0 else "", state.combo)

func _note_creature(data: CreatureData) -> void:
	state.max_level = maxi(state.max_level, data.level)


## The jar overflowed: everything stops, the record is checked and saved, the end window opens.
func _lose() -> void:
	state.over = true
	state.can_drop = false
	_jar.freeze_all()
	_jar.show_danger(0.0)
	_audio.play_sfx(SfxLibrary.LOSE)
	var new_record := Scoring.record(_profile, state.score)
	var saved := SaveStore.save(_profile, _options)

	_end.set_audio(_audio)
	_end.again_requested.connect(_restart)
	_end.quit_requested.connect(_quit)
	add_child(_end)
	if _autopilot:
		_autopilot.on_round_over({"score": state.score, "max_level": state.max_level,

func _restart() -> void:
	if _end:
		_end.queue_free()
		_end = null
	_start_round()


## Back to the title; a Game run on its own (nothing above it) quits instead.
func _quit() -> void:
	if get_parent() == get_tree().root:
		get_tree().quit()
		return
	quit_to_title.emit()
```

Replace `scripts/game/game_autoplay.gd` with:

```gdscript
class_name GameAutoplay extends Node
## Node, a piece of Game, only with --autoplay: plays rounds by itself. Each time a creature
## waits it thinks THINK seconds and drops it over the highest settled creature of its own level,
## or, with none, where the pile is lowest (_choose_x()). It prints what a reader of the log
## follows: each drop (`Suelta: gota en x=1.2`), merge (`Fusión: slime_azul (combo 2)`) and new
## creature (`Nueva: lobo`), the result of each round (`Partida: 1240 puntos, máxima golem,
## 3 min 10 s`) and, with --autoplay-games=N, the averages of the N rounds (`Media de ...`); with
## --autoplay-save, the save written and read back after each round (`Guardado:` and `Cargado:`,
## the same). END_WAIT seconds after a round it starts the next (restart) or, after the last,
## asks to quit (quit_requested). Each round it checks that no creature left the plane. Uses only
## Game's Callables (drop, restart) and the Jar's public functions; never stores Game or a Jar
## (it asks jar_of each time: the Jar changes every round).

signal quit_requested

## Seconds the end window stays before the next round (or the quit).
const END_WAIT := 1.0
## How finely it looks for the lowest place of the pile, in metres.
const SCAN_STEP := 0.25
## A creature farther than this from z 0 has left the plane: the axis lock failed.
const DRIFT_LIMIT := 0.01
## The averages count the rounds that reached this level (the spec asks for the 6, the Lobo de
## niebla, in most of them).
const GOAL_LEVEL := 6

## drop.call(x): Game.drop_at().
var drop: Callable
## restart.call(): Game's Otra vez.

var _state_of: Callable
var _jar_of: Callable

var _print_save := false

## Counts down after a round; below 0, no round is over.
var _end_wait := -1.0
var _results: Array[Dictionary] = []


## state_of and jar_of return the current GameState and Jar; games is --autoplay-games,
## print_save --autoplay-save.
func setup(state_of: Callable, jar_of: Callable, games: int, print_save: bool) -> void:
	_state_of = state_of
	_jar_of = jar_of
	_games = games
	_print_save = print_save


## Every physics frame (Game._physics_process()), also while a round is over.
func step(delta: float) -> void:
	if _end_wait >= 0.0:
		_end_wait -= delta
		if _end_wait < 0.0:
			_next_round()
		return
	var state: GameState = _state_of.call()
	if state.over or not state.can_drop:
		_think = THINK
		return
	_think -= delta
	if _think > 0.0:
		return
	_think = THINK
	var jar: Jar = _jar_of.call()
	drop.call(_choose_x(Chain.data(state.current), jar.creatures()))


func on_dropped(id: String, x: float) -> void:
	print("Suelta: %s en x=%.1f" % [id, x])

func on_merged(id: String, combo: int) -> void:
	if id == "":
		var top: String = Chain.IDS[Chain.MAX_LEVEL - 1]
		print("Fusión: %s + %s (combo %d)" % [top, top, combo])
		return
	print("Fusión: %s (combo %d)" % [id, combo])


## result: score, max_level, seconds, new_record; saved: what SaveStore wrote ({} if nothing).
func on_round_over(result: Dictionary, saved: Dictionary) -> void:
	_check_plane()
	print("Partida: %d puntos, máxima %s, %s" % [result.score, Chain.IDS[result.max_level - 1],
		GameState.time_text(result.seconds)])
	if _print_save:
		_print_round_trip(saved)
	_results.append(result)
	_end_wait = END_WAIT


func _next_round() -> void:
	if _results.size() < _games:
		restart.call()
		return
	if _games > 1:
		_print_averages()
	quit_requested.emit()


## Over the highest settled creature of data's level; with none, where the pile is lowest
## (the middle wins a tie).
func _choose_x(data: CreatureData, bodies: Array[CreatureBody]) -> float:
	var best: CreatureBody = null
	for body in bodies:
		if body.merged or body.data.level != data.level or body.age < JarSpec.SETTLE_TIME:
			continue
		if best == null or body.position.y > best.position.y:
			best = body
	if best:
		return JarSpec.clamp_x(best.position.x, data.radius)
	var low_x := 0.0
	var low_y := INF
	var x := -JarSpec.WIDTH / 2.0 + data.radius
	while x <= JarSpec.WIDTH / 2.0 - data.radius + 0.001:
		var y := _rest_height(x, data.radius, bodies)
		if y < low_y - 0.01 or (absf(y - low_y) <= 0.01 and absf(x) < absf(low_x)):
			low_y = y
			low_x = x
		x += SCAN_STEP
	return low_x


## Where the centre of a creature of radius falling at x would come to rest on the pile.
func _rest_height(x: float, radius: float, bodies: Array[CreatureBody]) -> float:
	var y := radius
	for body in bodies:
		var reach := body.data.radius + radius
		var dx := absf(body.position.x - x)
		if dx < reach:
			y = maxf(y, body.position.y + sqrt(reach * reach - dx * dx))
	return y


## "Media de 20 partidas: 1532 puntos, máxima lobo (12 de 20), 4 min 5 s, 6 o más en 15 de 20".
func _print_averages() -> void:
	var points := 0
	var seconds := 0.0
	var counts := {}
	var goal := 0
	for result in _results:
		points += int(result.score)
		seconds += float(result.seconds)
		var level: int = result.max_level
		counts[level] = counts.get(level, 0) + 1
		if level >= GOAL_LEVEL:
			goal += 1
	var top := 0
	for level: int in counts:
		if top == 0 or counts[level] > counts[top] or (counts[level] == counts[top] and level > top):
			top = level
	var n := _results.size()
	print("Media de %d partidas: %d puntos, máxima %s (%d de %d), %s, %d o más en %d de %d" % [
		n, roundi(points / float(n)), Chain.IDS[top - 1], counts[top], n,
		GameState.time_text(seconds / n), GOAL_LEVEL, goal, n])


## The save written and the same save read back from the file into a fresh profile and options:
## the two lines must be identical.
func _print_round_trip(saved: Dictionary) -> void:
	var profile := Profile.new()
	var options := GameOptions.new()
	SaveStore.load_into(profile, options)
	print("Guardado: %s" % JSON.stringify(saved))
	print("Cargado: %s" % JSON.stringify(SaveData.from(profile, options)))


## The creatures are locked on Z: one away from z 0 means the lock failed.
func _check_plane() -> void:
	var jar: Jar = _jar_of.call()
	for body in jar.creatures():
		if absf(body.position.z) > DRIFT_LIMIT:
			push_warning("Una criatura se ha salido del plano: %s en z=%.3f"
				% [body.data.id, body.position.z])
			return
```

```gdscript
func pop(figure: Node3D) -> void:
	figure.scale = Vector3.ONE * POP_FROM
	var tween := figure.create_tween()
	tween.tween_property(figure, "scale", Vector3.ONE * POP_OVER, POP_TIME * 0.6)
	tween.tween_property(figure, "scale", Vector3.ONE, POP_TIME * 0.4)


func burst(at: Vector3, color: Color, amount := BURST, speed := BURST_SPEED) -> void:
	var particles := CPUParticles3D.new()
	particles.one_shot = true
	particles.explosiveness = 1.0
	particles.amount = amount
	particles.lifetime = PARTICLE_LIFE
	particles.direction = Vector3.UP
	particles.spread = 180.0
	particles.flatness = 1.0
	particles.initial_velocity_min = speed * 0.5
	particles.initial_velocity_max = speed
	particles.gravity = PARTICLE_GRAVITY
	particles.scale_amount_min = 0.6
	particles.scale_amount_max = 1.2
	particles.color = color
	var mesh := LowPoly.sphere(PARTICLE_SIZE)
	var material := StandardMaterial3D.new()
	material.shading_mode = BaseMaterial3D.SHADING_MODE_UNSHADED
	material.vertex_color_use_as_albedo = true
	mesh.material = material
	particles.mesh = mesh
	particles.position = Vector3(at.x, at.y, JarBuilder.FRONT_Z)
	add_child(particles)
	particles.emitting = true
	get_tree().create_timer(PARTICLE_LIFE + 0.2, false).timeout.connect(particles.queue_free)


## Two of the last level (radius) vanish at at: a big burst in the accent and a glow that grows
## and fades.
func flash(at: Vector3, radius: float) -> void:

	var glow := MeshInstance3D.new()

	glow.material_override = material
	glow.position = Vector3(at.x, at.y, JarBuilder.FRONT_Z - radius)
	add_child(glow)
	var tween := glow.create_tween().set_parallel()
	tween.tween_property(glow, "scale", Vector3.ONE * FLASH_GROWTH, FLASH_TIME)
	tween.tween_property(material, "albedo_color:a", 0.0, FLASH_TIME)
	tween.chain().tween_callback(glow.queue_free)


## "+30" over at, rising RISE in RISE_TIME and fading.
func points(at: Vector3, value: int) -> void:
	var label := Label3D.new()
	label.text = "+%d" % value
	UiTheme.style_3d(label, &"title-m", &"text-accent", UiTokens.OUTLINE_M)
	label.pixel_size = LABEL_PIXEL
	label.no_depth_test = true
	label.position = Vector3(at.x, at.y, JarBuilder.FRONT_Z + 0.1)
	add_child(label)
	var tween := label.create_tween().set_parallel()
	tween.tween_property(label, "position:y", at.y + RISE, RISE_TIME)
	tween.tween_property(label, "modulate:a", 0.0, RISE_TIME).set_ease(Tween.EASE_IN)
	tween.tween_property(label, "outline_modulate:a", 0.0, RISE_TIME).set_ease(Tween.EASE_IN)
	tween.chain().tween_callback(label.queue_free)
```

```gdscript
## A ball's side profile, bottom to top, RINGS + 1 rings.
static func _ball(radius: float) -> Array[Vector2]:
	var profile: Array[Vector2] = []
	for i in RINGS + 1:
		var angle := PI * i / RINGS
		profile.append(Vector2(radius * sin(angle), -radius * cos(angle)))
	return profile


## A drop: the bottom half of a ball, then narrowing to a tip 1.4 radii up.
static func _drop(r: float) -> Array[Vector2]:
	return [Vector2(0.0, -r), Vector2(0.5 * r, -0.866 * r), Vector2(0.866 * r, -0.5 * r),
		Vector2(r, 0.0), Vector2(0.8 * r, 0.55 * r), Vector2(0.45 * r, 0.95 * r),
		Vector2(0.0, 1.4 * r)]


## A slime: wide and almost flat at the bottom, lower on top.
static func _slime(r: float) -> Array[Vector2]:
	return [Vector2(0.0, -r), Vector2(0.8 * r, -0.95 * r), Vector2(r, -0.5 * r),
		Vector2(0.98 * r, 0.05 * r), Vector2(0.8 * r, 0.55 * r), Vector2(0.45 * r, 0.88 * r),
		Vector2(0.0, 0.95 * r)]


## A dome of radius and height over a flat underside (the seta's cap, the golem's moss).
static func _dome(radius: float, height: float) -> Array[Vector2]:
	return [Vector2(0.0, 0.0), Vector2(radius, 0.0), Vector2(0.9 * radius, 0.4 * height),
		Vector2(0.62 * radius, 0.8 * height), Vector2(0.0, height)]


## Two cones for ears (or horns) on top, base radius and height in radii, at ±x, leaning out.
static func _ears(root: Node3D, r: float, radius: float, height: float, x: float,
		lean: float, material: Material) -> void:
	for side: float in [-1.0, 1.0]:
		_add(root, LowPoly.cone(radius * r, height * r), material,
			Vector3(side * x * r, 0.92 * r, 0.0), Vector3(0.0, 0.0, -side * lean))


## Two flat cones for wings, pointing out and a little up from the sides, behind the body.
static func _wings(root: Node3D, r: float, radius: float, length: float, x: float,
		y: float, material: Material) -> void:
	for side: float in [-1.0, 1.0]:
		_add(root, LowPoly.cone(radius * r, length * r), material,
			Vector3(side * x * r, y * r, -0.1 * r), Vector3(0.0, 0.0, -side * 75.0),
			Vector3(1.0, 1.0, 0.35))


## Two eyes on the front of a ball of radius r, at height y (times r), each with its shine.
static func _eyes(root: Node3D, r: float, y: float, silhouette: bool) -> void:
	for side: float in [-1.0, 1.0]:
		_add(root, LowPoly.sphere(0.14 * r), _paint(EYE_COLOR, silhouette),
			Vector3(side * 0.33 * r, y * r, 0.86 * r), Vector3.ZERO, Vector3(1.0, 1.15, 0.6))
		_add(root, LowPoly.sphere(0.05 * r), _paint(SHINE_COLOR, silhouette),
			Vector3(side * 0.33 * r + 0.04 * r, y * r + 0.06 * r, 0.95 * r))


static func _add(root: Node3D, mesh: Mesh, material: Material, at := Vector3.ZERO,
		degrees := Vector3.ZERO, scale := Vector3.ONE) -> MeshInstance3D:
	var node := MeshInstance3D.new()
	node.mesh = mesh
	node.material_override = material
	node.position = at
	node.rotation_degrees = degrees
	node.scale = scale
	root.add_child(node)
	return node


## The lit material of color (cached), or the silhouette's.
static func _paint(color: Color, silhouette: bool) -> Material:
	if silhouette:
		return _material(UiTokens.color(&"creature-silhouette"), true)
	return _material(color, false)


static func _material(color: Color, flat: bool) -> Material:
	var key := "%s:%s" % [color.to_html(), flat]
	if not _materials.has(key):
		var material := StandardMaterial3D.new()
		material.albedo_color = color
		material.roughness = ROUGHNESS
		if flat:
			material.shading_mode = BaseMaterial3D.SHADING_MODE_UNSHADED
		_materials[key] = material
	return _materials[key]
```

```gdscript
const OUT := "res://assets/pwa/icon_%d.png"
## The Gota is 2.4 radii tall (its tip is 1.4 up): the camera looks at its middle.
const GOTA_HEIGHT := 2.4
const GOTA_MIDDLE := 0.2


func _initialize() -> void:
	_run()


func _run() -> void:
	await process_frame
	DirAccess.make_dir_recursive_absolute(ProjectSettings.globalize_path("res://assets/pwa"))
	var view := SubViewport.new()
	view.size = Vector2i(SIZES[0], SIZES[0])
	view.own_world_3d = true
	view.render_target_update_mode = SubViewport.UPDATE_ALWAYS
	root.add_child(view)
	var stage := Node3D.new()
	view.add_child(stage)
	JarBuilder.backdrop(stage, false)
	var gota := Chain.data(1)
	var figure := CreatureLooks.build(gota)
	figure.position = Vector3(0.0, JarSpec.VIEW_CENTER_Y, 0.0)
	stage.add_child(figure)
	var camera := Camera3D.new()
	camera.projection = Camera3D.PROJECTION_ORTHOGONAL
	camera.size = gota.radius * GOTA_HEIGHT / ICON_FILL
	camera.position = Vector3(0.0, JarSpec.VIEW_CENTER_Y + gota.radius * GOTA_MIDDLE, 20.0)
	stage.add_child(camera)
	camera.current = true
	for frame in 8:
		await process_frame
	await RenderingServer.frame_post_draw
	var image := view.get_texture().get_image()
	for side in SIZES:
		var copy := image.duplicate() as Image
		if side != SIZES[0]:
			copy.resize(side, side, Image.INTERPOLATE_LANCZOS)
		copy.save_png(OUT % side)
		print("Icono: %s" % (OUT % side))
	quit()
```
