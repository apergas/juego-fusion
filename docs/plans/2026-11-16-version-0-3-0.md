# Version 0.3.0 (helps and music) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use boost:subagent-driven-development (recommended) or boost:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the two helps of a round, «Romper» (take one tapped creature out of the jar) and «Cambiar» (swap the waiting creature with «Siguiente»), earned by play and kept with the half jar, and two calm tunes synthesized in code (the title's and the jar's) with a «Música» volume in Opciones. Spec: [`docs/specs/2026-11-16-version-0-3-0-design.md`](../specs/2026-11-16-version-0-3-0-design.md).

**Starts after 0.2.0 is merged into `develop`:** this plan relies on `RoundSnapshot`, `Profile.saved_round`, `SaveData` version 2, `Game.keep_round()` / `resume_round()`, `tests/fixtures.gd`, the `design/` folder and the silent bestiary, all from 0.2.0 ([plan](../legacy/plans/2026-11-16-version-0-2-0.md)).

**Architecture:** As before (pure rules, static builders, nodes; `Game` a coordinator). New pure rules: `PowerUps` (charges, earning, what Cambiar and Romper need, which creature is under the finger) on two new `GameState` fields, and `MusicScore` (the tunes as note tables and their reading). New builder: `MusicLibrary` (renders `MusicScore` into looping streams, from Villaclaro's). New nodes: `PowerButton` (a help's button in the `Hud`) and `BreakPicker` (a piece of `Game` that takes Romper's tap while the tree is paused). `AudioDirector` gains Villaclaro's two cross-fading music players.

**Tech Stack:** Godot 4.7.2, GDScript, Compatibility renderer, Jolt Physics, the design system core (git submodule `addons/design_system/`), GUT 9.7.1, Git Bash on Windows (`./tools/godot.cmd`).

## Decisions this plan takes where the spec leaves room

- **Charges on `GameState`** (`breaks`, `swaps`), worked by the pure `PowerUps`, so `RoundSnapshot` keeps them with the round (optional keys: a 0.2.0 round gets `START`).
- **`PowerUps.earn(state, old_score, old_max)`** runs after each merge, with the score and the biggest before it; it returns what was really earned (after the cap).
- **Romper pauses the whole tree** (`get_tree().paused`), like the pause: the physics and every clock stop for free. `BreakPicker` (`PROCESS_MODE_ALWAYS`, a piece of `Game`, never of the `Jar`) takes the next tap; the helps' `PowerButton`s keep processing too; the pause button does not (the pause can't open from the HUD while choosing, but losing the focus stops the choosing first and then opens it).
- **Which creature is under the finger** is the pure `PowerUps.hit()` over circles the `Jar` gives (`creature_at()`), so the overlap rule is tested.
- **The hint** is a Label of the `Hud` at `hud-combo-top` (no combo can show while the tree is paused); the token's doc says it is shared.
- **The buttons** sit in a bottom row of the `Hud`, `SPACE_4` from the edge: about 80 canvas units, under the 110 the camera leaves below the jar's floor frame on a 720 × 1280 screen (more on taller phones). New token `power-button-w` 176 px; height `hud-button` (64, over `touch-target` 56).
- **Autoplay's policy:** Cambiar right before a drop when the waiting creature has no settled mate and «Siguiente» has one; Romper when the danger has counted `BREAK_AT` 1.5 s, the settled creature that reaches highest, not again for `BREAK_GAP` 1.0 s.
- **Music:** `MusicScore` holds the tables and the parser (pure, tested in `tests/audio/`); `MusicLibrary` (builder) renders them with `SfxLibrary.to_stream(samples, rate)`, which gains a `rate` argument. Only the hi-hat (`"h"`) of Villaclaro's drums is kept. `AudioDirector.set_volume(sfx)` becomes `set_volumes(music, sfx)`. The title plays `title` when it opens; `Game` plays `jar` in `_ready()`; the music goes on under the pause and the end window.
- **`Game` grows to about 400 lines** (helps' wiring and Romper's choosing); the choosing input lives in its own piece (`BreakPicker`) so `Game` keeps only the coordination.

Create `scripts/game/power_ups.gd`:

```gdscript
class_name PowerUps extends RefCounted
## The two helps of a round. Romper takes one creature the player taps out of the jar; Cambiar
## swaps the waiting creature with «Siguiente». Pure: works on a GameState (breaks, swaps). A round
## starts with START of each (start()); Cambiar earns one every SWAP_EVERY points and Romper one
## each time the round's biggest reaches a new level from BREAK_FROM_LEVEL on (earn(), after each
## merge); neither holds more than MAX. hit() tells which creature is under the finger.

const START := 1
const MAX := 3
const SWAP_EVERY := 1000
const BREAK_FROM_LEVEL := 6


static func start(state: GameState) -> void:
	state.breaks = START
	state.swaps = START


## After a merge that raised the score from old_score and the biggest from old_max: the helps
## earned are added (capped at MAX). Returns what was really earned: {"breaks", "swaps"}.
static func earn(state: GameState, old_score: int, old_max: int) -> Dictionary:
	var swaps := floori(state.score / float(SWAP_EVERY)) - floori(old_score / float(SWAP_EVERY))
	var breaks := maxi(0, state.max_level - maxi(old_max, BREAK_FROM_LEVEL - 1))
	var had_breaks := state.breaks
	var had_swaps := state.swaps
	state.breaks = mini(MAX, state.breaks + breaks)
	state.swaps = mini(MAX, state.swaps + maxi(0, swaps))
	return {"breaks": state.breaks - had_breaks, "swaps": state.swaps - had_swaps}


## Cambiar needs a charge, a creature waiting, «Siguiente» different from it and a round on.
static func can_swap(state: GameState) -> bool:
	return state.swaps > 0 and state.can_drop and not state.over and state.current != state.next


## The waiting creature and «Siguiente» change places and a charge goes; false (nothing changed)
## if Cambiar can't be used.
static func swap(state: GameState) -> bool:
	if not can_swap(state):
		return false
	var waiting := state.current
	state.current = state.next
	state.next = waiting
	state.swaps -= 1
	return true


## Romper needs a charge, a creature in the jar (creatures: how many) and a round on.
static func can_break(state: GameState, creatures: int) -> bool:
	return state.breaks > 0 and not state.over and creatures > 0


## A charge of Romper goes; false (nothing changed) without one or with the round over.
static func use_break(state: GameState) -> bool:
	if state.breaks <= 0 or state.over:
		return false
	state.breaks -= 1
	return true


## The index of the creature under point, among circles of centres and radii: of the ones point
## is inside, the one whose centre is nearest; -1 for none.
static func hit(point: Vector2, centres: Array[Vector2], radii: Array[float]) -> int:
	var best := -1
	var best_distance := INF
	for i in centres.size():
		var distance := point.distance_to(centres[i])
		if distance <= radii[i] and distance < best_distance:
			best = i
			best_distance = distance
	return best
```

```gdscript
func creature_at(point: Vector2) -> CreatureBody:
	var free: Array[CreatureBody] = []
	var centres: Array[Vector2] = []
	var radii: Array[float] = []
	for body in _bodies:
		if body.merged:
			continue
		free.append(body)
		centres.append(Vector2(body.position.x, body.position.y))
```

```gdscript
## The game's two tunes, written as note tables, and how to read them. Pure: no nodes and no sound
## (MusicLibrary renders them). The pattern of Villaclaro's MusicLibrary, with this game's own
## tunes: TITLE, calm, for the title, and JAR, a little livelier, for the jar; both loop. Each

const TITLE := "title"
const JAR := "jar"

const BAR := 16
const REST := "r"
const HAT := "h"

			"C5/4 A4/4 F#4/4 A4/4", "G4/12 r/4",

		"bass": [

## Bars -> [[pitch in Hz (0.0 a rest) or HAT, length in sixteenths], ...]. A token without its
## length lasts 0 (and its bar comes out short).
static func parse(bars: Array) -> Array:
	var notes := []
	for bar: String in bars:
		for token in bar.split(" ", false):
			var parts := token.split("/")
			var length := parts[1].to_int() if parts.size() == 2 else 0
			var name := parts[0]
			if name == REST:
				notes.append([0.0, length])
			elif name == HAT:
				notes.append([HAT, length])
			else:
				notes.append([frequency(name), length])
	return notes


## The frequency in Hz of a note with its octave ("A4" is 440); 0.0 for one it can't read.
static func frequency(name: String) -> float:
	var note := name.left(-1)
	var octave := name.right(1)
	if not SEMITONES.has(note) or not octave.is_valid_int():
		return 0.0
	var midi := 12 * (octave.to_int() + 1) + int(SEMITONES[note])
	return 440.0 * pow(2.0, (midi - 69) / 12.0)


## The sixteenths parsed notes last.
static func steps(notes: Array) -> int:
	var total := 0
	for note: Array in notes:
		total += int(note[1])
	return total


## Seconds of one sixteenth at bpm.
static func step_seconds(bpm: int) -> float:
	return 60.0 / bpm / 4.0


## Seconds one loop of the tune id lasts (its lead).
static func seconds(id: String) -> float:
	var track: Dictionary = TRACKS[id]
	return steps(parse(track.lead)) * step_seconds(track.bpm)
```

```gdscript
class_name MusicLibrary extends RefCounted
## Constructor: static; renders MusicScore's tunes into looping AudioStreamWAV (RATE Hz, 16-bit
## mono, through SfxLibrary.to_stream()) for the AudioDirector, and keeps no state but a cache of
## streams and of the hi-hat: the lead in a square wave (the tune's duty), the bass in a triangle,
## the hi-hat in noise. Copied from Villaclaro's scripts/audio/music_library.gd, trimmed to what
## these tunes use; build() renders a tune once, the first time it plays (about 20 s of samples).

## If rendering a tune on the desktop takes more than 0.4 s, this goes down to 11025.
const RATE := 22050
const LEAD_VOLUME := 0.16
const BASS_VOLUME := 0.26
const HAT_VOLUME := 0.08
## Seconds of fade-in and fade-out of every note (no clicks between notes).
const ATTACK := 0.004
const RELEASE := 0.02
## The lead loses this share of its volume over each note, for a plucked sound.
const LEAD_DECAY := 0.45
const HAT_TIME := 0.04
const NOISE_SEED := 1234

static var _cache := {}
static var _hat := PackedFloat32Array()


## The tune id (a MusicScore id) as a looping stream, rendered on the first call.
static func build(id: String) -> AudioStreamWAV:
	if _cache.has(id):
		return _cache[id]
	var track: Dictionary = MusicScore.TRACKS[id]
	var step_frames := MusicScore.step_seconds(track.bpm) * RATE
	var lead := MusicScore.parse(track.lead)
	var total := MusicScore.steps(lead)
	var frames := int(total * step_frames)
	var mix := PackedFloat32Array()
	mix.resize(frames)
	mix.fill(0.0)
	_add_voice(mix, lead, total, step_frames, track.duty, LEAD_VOLUME, LEAD_DECAY)
	_add_voice(mix, MusicScore.parse(track.bass), total, step_frames, -1.0, BASS_VOLUME, 0.0)
	_add_hats(mix, MusicScore.parse(track.drums), total, step_frames)
	var stream := SfxLibrary.to_stream(mix, RATE)
	stream.loop_mode = AudioStreamWAV.LOOP_FORWARD
	stream.loop_begin = 0
	stream.loop_end = frames
	_cache[id] = stream
	return stream


## Drops the cached streams (AudioDirector._exit_tree()), so none is left at exit.
static func clear_cache() -> void:
	_cache.clear()
	_hat = PackedFloat32Array()


## Plays notes from the start, repeating them until total sixteenths. duty < 0 is a triangle wave,
## otherwise a square wave with that duty cycle.
static func _add_voice(mix: PackedFloat32Array, notes: Array, total: int, step_frames: float,
		duty: float, volume: float, decay: float) -> void:
	if notes.is_empty():
		return
	var step := 0
	var index := 0
	while step < total:
		var note: Array = notes[index % notes.size()]
		var length: int = mini(note[1], total - step)
		var freq: float = note[0]
		if freq > 0.0:
			_add_tone(mix, int(step * step_frames), int(length * step_frames), freq, duty,
				volume, decay)
		step += length
		index += 1


static func _add_tone(mix: PackedFloat32Array, start: int, count: int, freq: float,
		duty: float, volume: float, decay: float) -> void:
	var attack := int(ATTACK * RATE)
	var release := int(RELEASE * RATE)
	var inc := freq / RATE
	var phase := 0.0
	count = mini(count, mix.size() - start)
	for i in count:
		var env := 1.0 - decay * i / count
		if i < attack:
			env *= float(i) / attack
		elif i > count - release:
			env *= float(count - i) / release
		var wave: float
		if duty < 0.0:
			wave = 4.0 * absf(phase - 0.5) - 1.0
		else:
			wave = 1.0 if phase < duty else -1.0
		mix[start + i] += wave * volume * env
		phase += inc
		if phase >= 1.0:
			phase -= 1.0


## The hi-hat on every HAT of hits, repeated until total sixteenths.
static func _add_hats(mix: PackedFloat32Array, hits: Array, total: int,
		step_frames: float) -> void:
	if hits.is_empty():
		return
	var hat := _hat_sound()
	var step := 0
	var index := 0
	while step < total:
		var hit: Array = hits[index % hits.size()]
		if hit[0] is String:
			var start := int(step * step_frames)
			for i in mini(hat.size(), mix.size() - start):
				mix[start + i] += hat[i]
		step += int(hit[1])
		index += 1


## One hi-hat hit, computed once: noise that fades out fast.
static func _hat_sound() -> PackedFloat32Array:
	if not _hat.is_empty():
		return _hat
	var rng := RandomNumberGenerator.new()
	rng.seed = NOISE_SEED
	var count := int(HAT_TIME * RATE)
	_hat.resize(count)
	for i in count:
		var fade := 1.0 - float(i) / count
		_hat[i] = rng.randf_range(-1.0, 1.0) * 0.6 * fade * fade * HAT_VOLUME
	return _hat
```

```gdscript
class_name AudioDirector extends Node
## Plays the music and the sound effects. Copied from Villaclaro's scripts/audio/audio_director.gd,
## trimmed to the music and the effects (no ambient). Not an autoload: TitleScreen creates the only
## one and passes it on (Game, the windows). Two music players cross-fade over CROSSFADE seconds
## (MusicLibrary's tunes: the title's and the jar's); SFX_PLAYERS players take turns for the
## effects. With --autoplay everything plays the same but muted, and each tune started is printed
## with how long it took to render (`Música: jar (120 ms)`); on a headless run or while recording
## frames (--write-movie) the streams are built and set but never started: those audio drivers
## keep the playbacks alive at exit and Godot reports them as leaked. Keeps running while the tree
## is paused: the music goes on under the pause, and its buttons sound.

const CROSSFADE := 0.5
const SFX_PLAYERS := 6

var music_volume := GameOptions.DEFAULT_MUSIC
var sfx_volume := GameOptions.DEFAULT_SFX

var _music: Array[AudioStreamPlayer] = []
var _current := 0
var _music_id := ""
var _fade: Tween
var _sfx: Array[AudioStreamPlayer] = []
var _next_sfx := 0
var _muted := false
## Headless or --write-movie: never start a player.
var _no_playback := false
var _autoplay := false


func _ready() -> void:
	process_mode = Node.PROCESS_MODE_ALWAYS
	_autoplay = RunFlags.autoplay()
	_no_playback = DisplayServer.get_name() == "headless" \
		or Engine.get_write_movie_path() != ""
	_muted = _autoplay or _no_playback
	for i in 2:
		var player := AudioStreamPlayer.new()
		player.volume_linear = 0.0
		add_child(player)
		_music.append(player)
	for i in SFX_PLAYERS:
		var player := AudioStreamPlayer.new()
		add_child(player)
		_sfx.append(player)


## Empties the stream caches, so no stream is left at exit.
func _exit_tree() -> void:
	MusicLibrary.clear_cache()
	SfxLibrary.clear_cache()


## Cross-fades to the tune (a MusicScore id); does nothing if it already plays.
func play_music(id: String) -> void:
	if id == _music_id:
		return
	_music_id = id
	var started := Time.get_ticks_msec()
	var stream := MusicLibrary.build(id)
	if _autoplay:
		print("Música: %s (%d ms)" % [id, Time.get_ticks_msec() - started])
	var old := _music[_current]
	_current = 1 - _current
	var new := _music[_current]
	new.stream = stream
	new.volume_linear = 0.0
	_start(new)
	if _fade:
		_fade.kill()
	_fade = create_tween().set_parallel()
	_fade.tween_property(new, "volume_linear", _music_level(), CROSSFADE)
	_fade.tween_property(old, "volume_linear", 0.0, CROSSFADE)
	_fade.chain().tween_callback(old.stop)


func play_sfx(id: String) -> void:
	var player := _sfx[_next_sfx]
	_next_sfx = (_next_sfx + 1) % SFX_PLAYERS
	player.stream = SfxLibrary.build(id)
	player.volume_linear = 0.0 if _muted else sfx_volume
	_start(player)


## Volumes 0..1. The music changes at once (a cross-fade ends where it is); the effects from the
## next one.
func set_volumes(music: float, sfx: float) -> void:
	music_volume = music
	sfx_volume = sfx
	if _fade:
		_fade.kill()
	for i in 2:
		var player := _music[i]
		if i == _current and _music_id != "":
			player.volume_linear = _music_level()
		else:
			player.volume_linear = 0.0
			player.stop()


func _start(player: AudioStreamPlayer) -> void:
	if not _no_playback:
		player.play()


func _music_level() -> float:
	return 0.0 if _muted else music_volume
```
