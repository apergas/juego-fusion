# Version 0.2.0 (more comfortable) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use boost:subagent-driven-development (recommended) or boost:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** First move the game's design-system layer from `docs/design-system/` to its own top-level folder `design/`; then make *¡Plop!* more comfortable on a phone without changing the game: creatures are discovered in silence, the round pauses by itself when the game goes to the background, a round in progress survives closing the game (the title offers «Seguir»), and three cheap visible fixes from the 0.1.0 reviews. Spec: [`docs/specs/2026-11-16-version-0-2-0-design.md`](../specs/2026-11-16-version-0-2-0-design.md).

**Architecture:** As in 0.1.0 (pure rules, static builders, nodes; `Game` a coordinator over its pieces). One new pure rule, `RoundSnapshot` (a round ⇄ a `Dictionary`, with its validation), kept in `Profile.saved_round` and written by `SaveData` version 2 (version 1 migrated). The `Jar` gives its creatures as snapshots (`snapshot()`) and rebuilds bodies from them (`rebuild()`); `Game` keeps the round whenever the player leaves it (`keep_round()`) and plays a kept one back (`resume_round()`); `TitleScreen` offers «Seguir» and asks before «Jugar» throws one away (`ConfirmWindow`).

**Tech Stack:** Godot 4.7.2, GDScript, Compatibility renderer, Jolt Physics, the design system core (git submodule `addons/design_system/`), GUT 9.7.1 (`addons/gut/`), Git Bash on Windows (`./tools/godot.cmd`).

## Global Constraints

Every task's requirements implicitly include this section.

- **TESTS REQUIRED** (CLAUDE.md, *Tests*): every task that adds or changes a pure rule (`scripts/game/`, `RefCounted` / `Resource`) or the creatures' data adds or updates its GUT tests in the same commit, and every task ends by running the whole suite: `APPDATA="C:/Users/peixe/AppData/Local/Temp/juego-fusion-gut/appdata" ./tools/godot.cmd --headless --path . --script res://addons/gut/gut_cmdln.gd` must exit 0, with no `ERROR` line in its output but those a test expects with `assert_push_error` / `assert_engine_error` (e.g. `test_chain.gd`'s unknown id; GUT counts them, an unexpected one fails the run) (`mkdir -p` the folder first). Tests check rules and data only: **never nodes, scenes, constructors, UI, visuals, sound or files**; no test calls `SaveStore` or `FileAccess`, or changes a loaded `data/*.tres`. Each test file `extends GutTest`, starts with a `##` header, has no `class_name`; each test is `func test_<what must hold>() -> void:`; shared builders go in `tests/fixtures.gd`. A failing test is a bug in the game or in the test: never loosen it to pass.

## Decisions this plan takes where the spec leaves room

- **Dependabot for the core** (Task 1): `gitsubmodule`, weekly, to `develop`, merged by hand; `tests.yml` also runs on pull requests to `develop` and runs, after `--import`, the two design-system checks (they only lived in `pages.yml`), GUT and a two-round seeded headless autoplay judged like the skill's runs, so its pull request is checked before anyone merges it. The CHANGELOG names the core's tag from 0.2.0 on.
- **The layer's move comes first** (Task 1), so every later task already writes `design/`. Only the game's config (`design_system.json`) changes: the core reads every path from it and is never edited. The legacy 0.1.0 plan keeps its old paths as written (the record); the legacy spec's live link to the mockup is fixed.
- **Where the kept round lives:** `Profile.saved_round` (`{}` for none), next to the record and the bestiary, so `SaveStore.save(profile, options)` keeps its signature. `SaveData.from()` always writes `"round"`.
- **When it is written:** `Game.keep_round()` runs when the pause opens (so Esc, the HUD button, losing the focus and «Salir al título» are all covered) and on `NOTIFICATION_WM_CLOSE_REQUEST`. A new round forgets it and saves at once only if one was kept (`Game._forget_round()`); a lost round forgets it inside the record's own save.
- **What a broken round does:** the whole file is refused (the 0.1.0 rule), because a played game can't write one. Positions are not validated beyond being numbers: `RoundSnapshot.creatures_of()` clamps each x into the jar.
- **The resumed round opens in the pause** (spec), except on autoplay. `Game` is run on its own (`game.tscn`) never resumes.
- **The round trip check:** `RoundSnapshot.normalized()` writes a kept round again as `from()` would, so the round the game kept (ints) and the one the file gives back (floats) print the same; a unit test pins that, and `--autoplay-resume` prints both.
- **`ConfirmWindow`** is a small generic `ModalWindow` (title, one line, two answers); only the title uses it now.
- **Hiding the pause under Opciones:** `CanvasLayer.visible = false` on the `PauseWindow` while the `OptionsWindow` is open (its scrim goes too), back on close.
- **The bat's and dragon's wings:** `CreatureLooks._wings()` gains a `lean` argument; new numbers per creature (Task 3). No test (a constructor); checked on frames.
- **`Game` grows to about 330 lines** with `keep_round()`, `resume_round()`, `_notification()` and `_forget_round()`: well under 600 and all of it session coordination, so no new piece.

```gdscript
class_name RoundSnapshot extends RefCounted
## A round in progress as a Dictionary, so it survives closing the game (SaveData keeps it in the
## save's "round", Profile.saved_round), and back. Pure: no nodes, no files. The Jar gives each
## creature as creature() (its level, where it is, how it is turned and moving, its age); the rest
## is the GameState and the waiting creature's x. Spawner's generator goes as its state, written as
## a String (JSON would round a 64-bit number). The combo's clock is kept at most at
## Scoring.COMBO_WINDOW (later than that it is all the same, and JSON has no INF). is_valid()
## refuses what a round still going can't have: an unknown level, a negative score, a waiting
## creature Spawner can't give, a danger count already lost, more than MAX_CREATURES, a number
## that is not one; creatures_of() keeps each x inside the jar.

## More creatures than this never fit in the jar.
const MAX_CREATURES := 120


## One creature in the jar: its level, its centre in the plane, its turn around Z (radians), its
## velocity, its turning speed and its seconds in the jar.
static func creature(level: int, at: Vector2, angle: float, velocity: Vector2, spin: float,
		age: float) -> Dictionary:
	return {"level": level, "x": at.x, "y": at.y, "angle": angle, "vx": velocity.x,
		"vy": velocity.y, "spin": spin, "age": age}


## The round of state, with its creatures (creature() each) and the waiting creature's x.
static func from(state: GameState, creatures: Array[Dictionary], aim_x: float) -> Dictionary:
	return {"score": state.score, "combo": state.combo, "max_level": state.max_level,
		"since_merge": minf(state.since_merge, Scoring.COMBO_WINDOW),
		"current": state.current, "next": state.next, "can_drop": state.can_drop,
		"wait_left": state.wait_left, "aim_x": aim_x, "danger_time": state.danger_time,
		"elapsed": state.elapsed, "rng_state": str(state.rng.state),
		"creatures": creatures.duplicate(true)}


static func is_valid(data: Dictionary) -> bool:
	if not (_whole_from(data.get("score"), 0) and _whole_from(data.get("combo"), 0)):
		return false
	if not _whole_in(data.get("max_level"), 0, Chain.MAX_LEVEL):
		return false
	var top := Spawner.WEIGHTS.size()
	if not (_whole_in(data.get("current"), 1, top) and _whole_in(data.get("next"), 1, top)):
		return false
	if not data.get("can_drop") is bool:
		return false
	if not _number_in(data.get("wait_left"), 0.0, Spawner.DROP_WAIT):
		return false
	if not _number_in(data.get("since_merge"), 0.0, Scoring.COMBO_WINDOW):
		return false
	var danger: Variant = data.get("danger_time")
	if not _number_in(danger, 0.0, Danger.LOSE_TIME) or Danger.lost(float(danger)):
		return false
	if not _number_in(data.get("elapsed"), 0.0, INF) or not _number(data.get("aim_x")):
		return false
	var rng_state: Variant = data.get("rng_state")
	if not rng_state is String or not (rng_state as String).is_valid_int():
		return false
	var creatures: Variant = data.get("creatures")
	if not creatures is Array or (creatures as Array).size() > MAX_CREATURES:
		return false
	for item: Variant in creatures:
		if not _is_creature(item):
			return false
	return true


## The GameState of a valid round: its generator where it was, not over.
static func state_of(data: Dictionary) -> GameState:
	var state := GameState.new(0)
	state.rng.state = (data.rng_state as String).to_int()
	state.score = int(data.score)
	state.combo = int(data.combo)
	state.max_level = int(data.max_level)
	state.since_merge = float(data.since_merge)
	state.current = int(data.current)
	state.next = int(data.next)
	state.can_drop = data.can_drop
	state.wait_left = float(data.wait_left)
	state.danger_time = float(data.danger_time)
	state.elapsed = float(data.elapsed)
	return state


## The creatures of a valid round, ready for Jar.rebuild(): {"level", "at", "angle", "velocity",
## "spin", "age"}, each x kept inside the jar.
static func creatures_of(data: Dictionary) -> Array[Dictionary]:
	var list: Array[Dictionary] = []
	for item: Dictionary in data.creatures:
		var level := int(item.level)
		var radius := Chain.data(level).radius
		list.append({"level": level,
			"at": Vector2(JarSpec.clamp_x(float(item.x), radius), float(item.y)),
			"angle": float(item.angle), "velocity": Vector2(float(item.vx), float(item.vy)),
			"spin": float(item.spin), "age": float(item.age)})
	return list


static func aim_x_of(data: Dictionary) -> float:
	return float(data.aim_x)


## A valid round written again as from() would: the round the game kept (whole numbers) and the
## one the file gives back (every number a float) read the same (the autoplay's check).
static func normalized(data: Dictionary) -> Dictionary:
	var creatures: Array[Dictionary] = []
	for item in creatures_of(data):
		creatures.append(creature(item.level, item.at, item.angle, item.velocity, item.spin,
			item.age))
	return from(state_of(data), creatures, aim_x_of(data))


static func _is_creature(item: Variant) -> bool:
	if not item is Dictionary:
		return false
	var body: Dictionary = item
	if not _whole_in(body.get("level"), 1, Chain.MAX_LEVEL):
		return false
	for key: String in ["x", "y", "angle", "vx", "vy", "spin"]:
		if not _number(body.get(key)):
			return false
	return _number_in(body.get("age"), 0.0, INF)


## A finite number (JSON gives floats; the game keeps ints too).
static func _number(value: Variant) -> bool:
	return value is int or (value is float and is_finite(value))


static func _number_in(value: Variant, low: float, high: float) -> bool:
	return _number(value) and float(value) >= low and float(value) <= high


static func _whole_in(value: Variant, low: int, high: int) -> bool:
	return SaveData.whole(value) and int(value) >= low and int(value) <= high


static func _whole_from(value: Variant, low: int) -> bool:
	return SaveData.whole(value) and int(value) >= low
```

```gdscript
class_name SaveData extends RefCounted
## Turns the profile and the options into the Dictionary SaveStore writes as JSON, and back.
## Pure: no nodes, no files. VERSION 2: {"version", "best_score", "discovered", "options",
## "round"}; "round" is the round in progress the player left (RoundSnapshot), {} for none. A
## version 1 save (0.1.0's, without "round") is read as a 2 without a round (migrated()). A save
## of another version, or one a played game can't reach (a negative or broken record, an unknown
## or repeated id, no options, a broken round), is not valid, and nothing of it is applied: the
## game starts from scratch. JSON reads every number as a float, so apply() converts them.

const VERSION := 2
## The oldest version still read: 0.1.0's.
const OLDEST := 1


static func from(profile: Profile, options: GameOptions) -> Dictionary:
	return {"version": VERSION, "best_score": profile.best_score,
		"discovered": profile.discovered.duplicate(), "options": options.to_dict(),
		"round": profile.saved_round.duplicate(true)}


static func is_valid(data: Dictionary) -> bool:
	if not whole(data.get("version")):
		return false
	var version := int(data.version)
	if version < OLDEST or version > VERSION:
		return false
	var best: Variant = data.get("best_score")
	if not whole(best) or int(best) < 0:
		return false
	var ids: Variant = data.get("discovered")
	if not ids is Array:
		return false
	var seen := {}
	for id: Variant in ids:
		if not id is String or not Chain.IDS.has(id) or seen.has(id):
			return false
		seen[id] = true
	if not data.get("options") is Dictionary:
		return false
	if version == 1:
		return not data.has("round")
	var kept: Variant = data.get("round")
	if not kept is Dictionary:
		return false
	return (kept as Dictionary).is_empty() or RoundSnapshot.is_valid(kept)


## Puts a valid save into profile and options; false (and nothing changed) if it is not valid.
static func apply(data: Dictionary, profile: Profile, options: GameOptions) -> bool:
	if not is_valid(data):
		return false
	var current := migrated(data)
	profile.best_score = int(current.best_score)
	profile.discovered.assign(current.discovered)
	profile.saved_round = (current["round"] as Dictionary).duplicate(true)
	var loaded := GameOptions.from_dict(current.options)
	options.sfx_volume = loaded.sfx_volume
	options.vibration = loaded.vibration
	options.high_contrast = loaded.high_contrast
	return true


## A valid save in VERSION's shape: a version 1 save gets an empty round.
static func migrated(data: Dictionary) -> Dictionary:
	var current := data.duplicate(true)
	if int(current.version) == 1:
		current["round"] = {}
	current.version = VERSION
	return current


## A whole number, as JSON gives it back (a float with nothing after the point) or as an int.
static func whole(value: Variant) -> bool:
	if value is int:
		return true
	return value is float and is_equal_approx(value, roundf(value))
```

```gdscript
	_audio.play_sfx(SfxLibrary.DROP)
	if _autopilot:
		_autopilot.on_dropped(data.id, body.position.x)
	_note_creature(data)
	Spawner.advance(state)
	_hud.set_next(Chain.data(state.next))


## The pause window over a stopped jar (the whole tree pauses; the window keeps running). Not
## once the round is over. Opening it keeps the round (keep_round()).
func open_pause() -> void:
	if state == null or state.over or _pause:
		return
	keep_round()
	get_tree().paused = true
	_pause = PauseWindow.new()
	_pause.set_audio(_audio)
	_pause.resume_requested.connect(close_pause)
	_pause.options_requested.connect(_open_options)
	_pause.restart_requested.connect(func() -> void:
		close_pause()
		_restart())
	_pause.quit_requested.connect(func() -> void:
		close_pause()
		_quit())
	add_child(_pause)


func close_pause() -> void:
	if _pause == null:
		return
	_close_options()
	_pause.queue_free()
	_pause = null
	get_tree().paused = false


## The round still going into the profile (RoundSnapshot) and the save, so the title can offer
## Seguir: when the pause opens and when the window closes. Returns what was kept ({} if
## nothing: no round, or a lost one).
func keep_round() -> Dictionary:
	if state == null or state.over or _jar == null:
		return {}
	_profile.saved_round = RoundSnapshot.from(state, _jar.snapshot(), _jar.aim_x())
	SaveStore.save(_profile, _options)
	return _profile.saved_round


## A kept round (a valid RoundSnapshot) in place of the current one: its state, its creatures,
## the waiting one and its x. It opens in the pause (not on autoplay), so the player comes back
## ready.
func resume_round(data: Dictionary) -> void:
	state = RoundSnapshot.state_of(data)
	_new_jar()
	_jar.rebuild(RoundSnapshot.creatures_of(data))
	_show_round()
	if state.can_drop:
		_present()
	_jar.set_aim_x(RoundSnapshot.aim_x_of(data))
	if _autopilot == null:
		open_pause()


## Opciones over the pause: each change is put into effect and saved, as on the title. The pause
## (and its scrim) hides while it is open, so it never shows through.
func _open_options() -> void:
	if _options_window or _pause == null:
		return
	_pause.visible = false
	_options_window = OptionsWindow.new(_options)
	_options_window.set_audio(_audio)
	_options_window.changed.connect(_on_options_changed)
	_options_window.closed.connect(_close_options)
	add_child(_options_window)


func _close_options() -> void:
	if _options_window == null:
		return
	_options_window.queue_free()
	_options_window = null
	if _pause:
		_pause.visible = true


func _on_options_changed() -> void:
	_audio.set_volume(_options.sfx_volume)
	_audio.play_sfx(SfxLibrary.CURSOR)
	DisplaySettings.apply(get_window(), _options)
	SaveStore.save(_profile, _options)


## One physics frame of the round: its clocks, the jar, then the danger's count.
func _tick(delta: float) -> void:
	state.elapsed += delta
	state.since_merge += delta
	if not state.can_drop:
		state.wait_left -= delta
		if state.wait_left <= 0.0:
			_present()
	_jar.step(delta)
	var over := Danger.is_over(_jar.highest_top(JarSpec.SETTLE_TIME))
	state.danger_time = Danger.step(state.danger_time, over, delta)
	_jar.show_danger(Danger.fraction(state.danger_time))
	if Danger.lost(state.danger_time):
		_lose()


## A new round: the kept one is forgotten, a new GameState, its first creatures and a new Jar.
func _start_round() -> void:
	_forget_round()
	var seed_flag := RunFlags.seed()
	state = GameState.new(seed_flag + _round if seed_flag >= 0 else -1)
	_round += 1
	Spawner.start(state)
	_new_jar()
	_show_round()
	_present()


## A new Jar in place of the old one.
func _new_jar() -> void:
	if _jar:
		remove_child(_jar)
		_jar.queue_free()
	_jar = Jar.new()
	_jar.released.connect(drop_at)
	_jar.merge_found.connect(_on_merge_found)
	add_child(_jar)


## The HUD of the round in state.
func _show_round() -> void:
	_hud.clear()
	_hud.set_score(state.score)
	_hud.set_record(_profile.best_score)
	_hud.set_next(Chain.data(state.next))


## A new round throws the kept one away, and the save says so at once (only if there was one).
func _forget_round() -> void:
	if _profile.saved_round.is_empty():
		return
	_profile.saved_round = {}
	SaveStore.save(_profile, _options)


## The waiting creature appears at the top of the jar.
func _present() -> void:
	state.can_drop = true
	state.wait_left = 0.0
	_jar.show_waiting(Chain.data(state.current))


## Two equal creatures touch (the Jar's merge_found): the combo and the points (Scoring), then the
## creature they make (Chain), or nothing for two of the last level.
func _on_merge_found(a: CreatureBody, b: CreatureBody) -> void:
	if state.over:
		return
	var level := a.data.level
	state.combo = Scoring.next_combo(state.combo, state.since_merge)
	state.since_merge = 0.0
	var points := Scoring.points(Chain.merge_points(level), state.combo)
	state.score += points
	var made := Chain.next_level(level)
	var at := (a.position + b.position) / 2.0
	if made == 0:
		_jar.vanish(a, b)
		_audio.play_sfx(SfxLibrary.PRIZE)
	else:
		var data := Chain.data(made)
		_jar.merge(a, b, data)
		_audio.play_sfx(SfxLibrary.plop_id(made))
		_note_creature(data)
	_jar.show_points(at, points)
	_vibrate(made if made > 0 else Chain.MAX_LEVEL)
	_hud.set_score(state.score)
	_hud.show_combo(state.combo)
	if _autopilot:
		_autopilot.on_merged(Chain.IDS[made - 1] if made > 0 else "", state.combo)


## A creature has come into the jar (dropped or made by a merge): the round's biggest and, the
## first time ever, the bestiary, in silence: only a save (and the autoplay's line).
func _note_creature(data: CreatureData) -> void:
	state.max_level = maxi(state.max_level, data.level)
	if not Bestiary.discover(_profile, data.id):
		return
	SaveStore.save(_profile, _options)
	if _autopilot:
		_autopilot.on_discovered(data.id)


## A short vibration for a merge that makes level, if the player wants it (never on autoplay).
func _vibrate(level: int) -> void:
	if _options.vibration and _autopilot == null:
		Input.vibrate_handheld(Chain.vibration_ms(level))


## The jar overflowed: everything stops, the record is checked and saved (and the kept round
## forgotten in the same save), the end window opens.
func _lose() -> void:
	state.over = true
	state.can_drop = false
	_jar.freeze_all()
	_jar.show_danger(0.0)
	_audio.play_sfx(SfxLibrary.LOSE)
	var new_record := Scoring.record(_profile, state.score)
	_profile.saved_round = {}
	_hud.set_record(_profile.best_score)
	var saved := SaveStore.save(_profile, _options)
	_end = EndWindow.new(state.score, Chain.data(state.max_level).display_name, new_record)
	_end.set_audio(_audio)
	_end.again_requested.connect(_restart)
	_end.quit_requested.connect(_quit)
	add_child(_end)
	if _autopilot:
		_autopilot.on_round_over({"score": state.score, "max_level": state.max_level,
			"seconds": state.elapsed, "new_record": new_record}, saved)


## Otra vez: the end window goes and a new round starts.
func _restart() -> void:
	if _end:
		_end.queue_free()
		_end = null
	_start_round()


## Back to the title; a Game run on its own (nothing above it) quits instead.
func _quit() -> void:
	if get_parent() == get_tree().root:
		get_tree().quit()
		return
	quit_to_title.emit()
```
